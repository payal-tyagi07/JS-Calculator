# Calculator

A fully functional, stylish calculator web app built with HTML, CSS, and JavaScript. Features dark/light mode, keyboard support, and basic arithmetic operations.

## Features

- Basic operations: addition, subtraction, multiplication, division
- Clear (AC), backspace (⌫), sign toggle (+/-), percentage (%)
- Dark / Light mode toggle (default dark mode)
- Keyboard support (type numbers and operators)
- Responsive design, works on mobile and desktop
- Error handling for division by zero

## GitHub Link

https://github.com/payal-tyagi07/JS-Calculator

## Technologies Used

- HTML5
- CSS3 (Grid, Flexbox, custom properties)
- JavaScript (ES6)

## How to Use

1. Clone the repository or download the files.
2. Open `index.html` in any modern browser.
3. Click buttons or use your keyboard to calculate.

### Keyboard Shortcuts

| Key(s) | Action |
|--------|--------|
| `0`-`9` | Enter numbers |
| `.` | Decimal point |
| `+`, `-`, `*`, `/` | Operators |
| `Enter` or `=` | Equals / calculate |
| `Escape` | Clear all (AC) |
| `Backspace` | Delete last digit |
